# Yano Wallet

[Yano Wallet](https://github.com/bloxbean/yano-wallet) is a desktop Cardano wallet from BloxBean. It can connect to a
Yaci DevKit devnet, so you can test your dApp with a real wallet: create or restore accounts, sign with a Ledger,
and approve CIP-30 requests from your dApp in the browser.

<Callout type="warning">
Yano Wallet is in preview (`v0.1.0-pre5` at the time of writing) and has not been audited. Use it only with a local
devnet or a public test network. Do not use it on Mainnet, and do not restore a recovery phrase that holds real funds.
</Callout>

## What you get

- Software wallets and **Ledger** hardware wallets, with multiple accounts
- Send and receive ADA and native assets, staking, and governance voting
- A **CIP-30 dApp connector**: a browser extension that hands signing requests to the wallet
- **Simulate before you sign**: the approval prompt shows what a transaction does to your wallet before you sign it
- Transaction hashes link to Yaci Viewer at `http://localhost:5173`, where the [Docker](/getting-started/docker) distribution serves it

## How it connects

On other networks Yano Wallet runs its own Yano node. With Yaci DevKit it doesn't: it talks to the devnet's
**Yaci Store** over its Blockfrost-compatible API at `http://localhost:8080/api/v1`. Yaci Store must be running.

| Setting | Value |
|---|---|
| Network | `Yaci DevKit` (protocol magic 42) |
| Backend | External, Yaci Store |
| Default URL | `http://localhost:8080/api/v1` |

## Set it up

<Steps>

### Start a devnet with Yaci Store

```bash
yaci-devkit up --enable-yaci-store
```

The [Docker](/getting-started/docker) distribution starts Yaci Store by default.

### Install Yano Wallet

On an Apple Silicon Mac:

```bash
brew install --cask bloxbean/tap/yano-wallet
```

For Linux, Windows and Intel Macs, download a build from the
[releases page](https://github.com/bloxbean/yano-wallet/releases). The
[Getting Started guide](https://github.com/bloxbean/yano-wallet/blob/main/GETTING-STARTED.md) explains which file to pick.

### Connect to the devnet

On the wallet's **Connect** screen, choose the **Yaci DevKit** network. The wallet switches to an external backend and
fills in `http://localhost:8080/api/v1`. Change the URL if Yaci Store runs on another port, then click **Start**.

### Create a wallet and fund it

Create a new wallet, or connect a Ledger with the Cardano app open. Copy a receiving address, then top it up from the
Yaci CLI:

```bash
topup <address> 1000
```

You can also use the admin API at `http://localhost:10000`. See [Yaci CLI commands](/commands).

</Steps>

## Connect a dApp

To let a browser dApp use Yano Wallet:

1. Download `yano-connector-<version>.zip` from the same [release](https://github.com/bloxbean/yano-wallet/releases),
   unzip it, and load the folder as an unpacked extension at `chrome://extensions` (Developer mode on).
2. In the wallet, open **Settings → Browser connector** and click **Install browser connector (Native Messaging)**.
3. Restart the browser.

With the wallet running and unlocked, choose **Yano** in your dApp's wallet list. The dApp builds the transaction
against your devnet, and the wallet shows the approval prompt.

<Callout type="info">
Every Cardano test network reports CIP-30 `networkId` 0, so a dApp can't tell a devnet from Preprod by the network
id alone. Make sure your dApp and the wallet point at the same devnet.
</Callout>

## Yano Wallet or the built-in CIP-30 wallet?

Yaci DevKit also ships a [CIP-30 wallet](/cip30-wallet) at `http://localhost:10000/wallet`. Use it for automated tests
and quick checks: it needs no install and uses the devnet's pre-funded accounts. Use Yano Wallet when you want to
test with a real wallet, including hardware signing and the approval flow your users will see.

## Troubleshooting

- **The wallet can't connect.** Check that Yaci Store answers at `http://localhost:8080/api/v1/blocks/latest`.
- **Balances look wrong after resetting the devnet.** A reset starts a new chain. Top up the address again.
- **The dApp doesn't list Yano.** Check the extension is enabled, restart the browser after installing the connector,
  and reload the page.

More help is in the [Yano Wallet Getting Started guide](https://github.com/bloxbean/yano-wallet/blob/main/GETTING-STARTED.md#if-something-goes-wrong).

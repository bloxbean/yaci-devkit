How it works

Your whole stack, on localhost

Your off-chain code talks to the same APIs it uses on mainnet. DevKit runs the chain underneath, indexes every block, and gives you a CLI, an admin API, wallets and an explorer to drive it.

NewWorks with Yano Wallet

Sign with a real wallet

Yano Wallet is a desktop Cardano wallet designed for your custom devnet. Pick Yaci DevKit on its Connect screen and it runs on your devnet's Yaci Store, so you can approve your dApp's transactions in a real wallet before you ship.

  • Create or restore wallets, with multiple accounts
  • A CIP-30 browser connector: window.cardano.yano
  • Simulate before you sign: see what a transaction does first
  • Native assets, staking and governance votes
  1. 1$ yaci-devkit up --enable-yaci-storestart a devnet with Yaci Store
  2. 2$ brew install --cask bloxbean/tap/yano-walletmacOS · other platforms on GitHub
  3. 3Connect → Yaci DevKit → localhost:8080then topup your address
  4. 4Settings → Browser connectorfor dApps: load the connector extension, then install Native Messaging

Features

Built for how you build and test

From a quick script to a full end-to-end suite, DevKit gives you a chain you control: reset it, speed it up, fork it, fund it, and let your tools and agents drive it.

A devnet at any speed

Create a fresh chain in seconds and choose the block time: 1 second by default, or down to 100ms for fast test suites. Set epoch length, genesis and protocol parameters to match your scenario.

Node configuration
60 blocks / min
$ yaci-devkit up --block-time 1 --slot-length 1 --epoch-length 80
Yano

Node modes

Run a real Haskell node, or a lightweight Yano-only devnet.

Node modes
YanoJava node
cardano-nodeHaskell

Yano builds the chain fast, then hands it to cardano-node. You get a real Haskell node and its socket.

# node.properties nodeMode=companion

Blockfrost-compatible APIs

Yaci Store indexes every block and serves Blockfrost-compatible endpoints, so your SDK code just points at localhost. Script costs are evaluated with Scalus, so Ogmios is optional.

Get started

Install it your way

Four distributions, one CLI. Pick the one that fits your machine or your pipeline. They all share~/.yaci-cli.

terminal
# Install
$ brew install bloxbean/tap/yaci-devkit
 
# Start a devnet with Yaci Store
$ yaci-devkit up --enable-yaci-store
 
# Upgrade later
$ brew upgrade yaci-devkit
  • Native binary
  • brew upgrade
  • Settings in devkit.properties
